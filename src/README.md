# src/

**Purpose:** Application source for the OpenGrok app builder. TanStack Start + React.

| Path | Purpose |
|------|---------|
| `components/` | UI components |
| `lib/` | Shared libraries (auth, app data, AI, multiplayer) |
| `lib/ai/` | Server functions that call the xAI API |
| `routes/` | File-based routes (when present) |

Do not put native kernels, skills, or docs here. Those belong in `native/`, `skills/`, and `docs/`.
